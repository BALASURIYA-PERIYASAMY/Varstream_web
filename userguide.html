Quick Start Guide

Get up and running with APP NAME in minutes

1

First Launch

After installing APP NAME, launch it from your applications menu or desktop shortcut.

2

Welcome Screen

The first time you open APP NAME, you'll see a Welcome screen. Click "Get Started" to begin.

Create Account

Sign up for a free account to sync your work across devices and access cloud features.

Continue as Guest

Use APP NAME without an account. Some features will be limited.

3

Grant Permissions

APP NAME may request permissions for:

  • File System Access: To save and open your files
  • Network Access: For cloud sync and online features
  • Notifications: To alert you of important updates
Note: These permissions are optional and can be managed in Settings.
4

Create Your First Project

Once in the main interface, create your first project:

  1. Click the "New Project" button (or press Ctrl+N)
  2. Choose a template or start with a blank project
  3. Name your project and choose a save location
  4. Click "Create" to start working
5

Explore the Interface

Take a moment to familiarize yourself with the main interface. Hover over elements to see tooltips, and check out the Help menu for more resources.

Pro Tip: Press F1 anytime to access the help menu and keyboard shortcuts reference.

Saving and Exporting

Save your work and export in various formats

1

Save vs Export

  • Save (.project): Preserves all layers, edits, and project data for future editing
  • Export: Creates a final version in a specific format for sharing or publishing
2

Auto-Save Settings

Enable auto-save in Settings to automatically save your work:

  • Configure save intervals (every 5, 10, or 15 minutes)
  • Set maximum number of auto-saved versions
  • Choose auto-save location
3

Export Options

  • Format Selection: Choose from dozens of export formats
  • Quality Settings: Balance file size and quality
  • Batch Export: Export multiple files or pages at once
  • Presets: Save custom export settings for reuse

Troubleshooting

Solutions to common issues and problems

App Won't Start

Check System Requirements

Ensure your system meets the minimum requirements specified on the download page.

Restart Your Computer

A simple restart can resolve many startup issues.

Reinstall the Application

Completely uninstall and reinstall APP NAME to fix corrupted installations.

Performance Issues

Check Available Memory

Ensure you have sufficient RAM available. Close other applications if needed.

Clear Cache

Clear the application cache in Settings → Advanced → Clear Cache.

Reduce Project Complexity

Split large projects into smaller files or reduce the number of layers.

File Import/Export Issues

Check File Format

Ensure the file format is supported. Check the documentation for supported formats.

Check File Permissions

Ensure you have read/write permissions for the source and destination folders.

Update Application

Make sure you're using the latest version of APP NAME.

Cloud Sync Problems

Check Internet Connection

Ensure you have a stable internet connection.

Verify Login Credentials

Sign out and sign back in to refresh your authentication.

Manual Sync

Trigger a manual sync in Settings → Cloud → Sync Now.
